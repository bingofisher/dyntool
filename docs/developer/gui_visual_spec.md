# GUI 视觉规格说明

稳定性：`Private / implementation detail`

本页只保留当前 PySide6 GUI 的视觉合同摘要。旧版五页导航、独立导出页、左侧参数组堆叠、厚重卡片网格等草图已经废弃，不再作为实现依据。

## 当前主线

- 正式主导航固定为 `总览 / 导入与筛选 / 数据处理 / 图形绘制`。
- `SUBSET / EXPORT` 只作为内部状态或工作区能力，不恢复为独立主页面。
- 主界面采用 `摘要 + 主动作 + 结果主体`，复杂配置进入真实对话框。
- 导入参数、筛选规则、保存子集、处理参数、绘图设置和内部导出参数都通过对话框维护。
- 页面不使用 `QGroupBox` 作为普通卡片；摘要区统一使用轻量 `WorkspaceSection` 或结果面板。
- 底部任务面板只承担任务、日志、问题、导出记录和审查记录，不在页面内重复堆叠任务历史。

## 页面责任

| 页面 | 主界面保留 | 弹窗承载 |
|---|---|---|
| 总览 | 项目摘要、主样本集摘要、当前能力、近期记录、下一步动作 | 无复杂编辑 |
| 导入与筛选 | 项目目录、来源、检查摘要、绑定动作、子集摘要、预览表、已保存子集 | 导入参数、筛选规则、保存子集 |
| 数据处理 | 处理方法、范围摘要、执行和预览动作、结果表 | 处理范围、临时 UID、严格/覆盖开关、动作参数、预览字段 |
| 图形绘制 | 绘图模式、来源摘要、画布、渲染/保存/补算动作 | 主题、点数上限、保存格式和保存模式 |
| 内部导出能力 | 导出摘要、执行导出、补算入口 | 导出范围、类型、输出路径、格式、字段和选项 |

## 布局约束

- 2K 横屏下对象树目标宽度为 `170-180px`。
- 底部任务区目标高度为 `96-112px`。
- 主导航按钮高度不超过 `30px`。
- 页面头部高度不超过 `64px`。
- 数据处理和图形绘制左侧栏只保留主选择和主动作；复杂表单不得常驻。
- 处理页和图形页的主结果区必须明显大于左侧配置栏；子集页的 metadata 预览表必须是视觉主体，左侧筛选摘要和右侧已保存子集都属于辅助区。
- 顶部上下文条、导航条、状态摘要、空态和结果面板统一由 `ThemeManager + ThemeTokens` 通过 `objectName` / `surfaceRole` / `cardRole` 控制；页面代码不得再写散装颜色、边框和字号。
- `ProcessingMetricsFrame` 使用 `surfaceRole="summaryStrip"`；`PlottingEmptyStateLabel` 使用 `cardRole="inlineEmptyState"`，作为短状态条，不得恢复为大块说明卡。
- `PlottingCanvasSurface` 使用 `surfaceRole="plotCanvas"`，画布区域不能被结果详情页签挤压；结果页签保持低高度摘要。

## 筛选规则

子集筛选采用规则构建器而不是散装输入框：

- 支持 `and / or / not` 组合。
- 支持 `in / not in / = / != / > / >= / < / <= / contains / not contains / exists / not exists`。
- 字段路径固定为 `uid`、`alias`、`metadata.<field>`、`data.<slot>`、`result.<slot>`。
- 规则编辑器位于 `筛选规则` 对话框内，采用可增删列表组织条件和分组，支持复制、删除、上移、下移；metadata 分类字段提供候选值提示，不使用固定数量条件槽。
- 主界面只显示筛选摘要、预览命中和保存动作。

## 交互反馈

- 处理页中止入口固定靠近 `执行分析`；请求中止后按钮显示 `正在中止...`，并等待安全检查点完成协作式停止。
- 图形页切换模式、来源、样本、范围、点数上限、主题或保存模式后，底部摘要必须立即刷新；旧图仅作为上一次结果展示，保存入口和“导出当前图”在重新渲染前禁用。

## 审计要求

GUI 审计必须覆盖：

- 四页主导航不增加旧页面。
- 主流程入口生成可追踪的命令快照。
- 审计报告必须记录布局指标、规则快照、按钮禁用原因、绘图当前设置与画布快照一致性、导入/处理取消状态。
- 复杂配置入口打开真实对话框。
- 主页面不出现普通 `QGroupBox` 卡片。
- 截图非空白，画布或表格占据主工作区主体。
