# 核心库数值与存储一致性修正

稳定性：用户行为属于 `Public API`；提交实现属于 `Private / implementation detail`。

本次修正覆盖核心库，不涉及 GUI/Web，不指定新版本号，也不自动修改用户已有工程仓库。

## 数值与单位合同

积分、微分、响应谱和振动评价的求解边界使用相干 SI：秒、Hz、m/s²、m/s、m。
`calc_unit_system` 保留，用于解释没有显式单位的输入上下文；具有单位的模型以自身单位为准。
求解完成后才转换输出单位，切换 SI 或工程计算上下文不会改变物理结果。
ZVL、OTOVL、FDMVL 的参考加速度固定为 SI 下的 `1e-6 m/s²`；FPVDV 同时转换输入、加权加速度与剂量单位。

FFT 保留线性去趋势与 Hann 窗，按窗系数之和归一化，完整返回 `N//2+1` 个单边频点。
DC 与偶数长度的 Nyquist 分量不乘 2，其余正频率乘 2；相位按请求角度单位输出。
少于三个采样点无法形成有效 Hann 窗，直接报错。去趋势会移除常量和线性趋势，因此原信号的 DC 不作为保留量。

传递函数模型入口先将输出侧转换至输入侧的同量纲单位，再计算无量纲增益。
不同量纲模型，以及带单位模型与无单位对象的混合输入会被拒绝；原始数组调用者负责保证两侧单位一致。

分窗评价要求至少一个完整窗口。记录不足时错误包含实际点数、实际时长及所需窗口。
ZVL/OTOVL 可以显式使用 `time_windows=-1` 计算全记录窗口；FDMVL 仍要求完整的默认窗口。
程序不会自动缩短窗口。很短的示例记录使用全记录窗口只是 API 演示，不代替实际评价所需的测量时长。

CSV 解析所有数据列的单位。等价写法正常读取，不同尺度或不同量纲需由调用者预先统一。
无单位列使用显式输入单位或默认单位；带单位表头优先，不能通过显式参数静默重新标记已有表头。

## 比较合同

`compare_with()` 将同名标量和特征转换为固定 SI 数值后应用 `rtol/atol`。
绝对容差的单位随字段量纲确定，例如 `pga`、`zvl.aw` 是 m/s²，`pgv` 是 m/s，`pgd` 是 m。
分贝与无量纲值保留本来的语义。差异表仍使用原来的列结构，其左右数值采用上述规范单位。
双方均缺失视为相同，单方缺失报告差异。存储摘要快路径与内存路径遵守相同规则。
普通 `scalar_frame()` 继续使用当前显示单位；比较不会改变原模型单位。

## 保存合同

| 参数或情形 | 行为 |
|---|---|
| `categories=None` | 更新全部可保存的非空槽位 |
| `categories=[]` | 不修改数据或 metadata |
| 非空选择 | 更新选中的非空槽位，保留磁盘其他槽位 |
| 选中槽位明确为 `None` | 保留磁盘原值，不隐式删除 |
| 懒槽位尚未加载 | 不等于空；同目标部分更新不为保留其他槽位而加载 payload |
| 保存至新目标 | 仅写所选数据，需要时只补载所选源槽位 |
| `strict=True` | 首个失败停止，先前提交的样本保留 |
| `strict=False` | 可恢复的样本错误记录到报告并继续；全局 I/O、连接失效或回滚失败停止 |

原子提交单位是单个样本，不提供整批回滚。进度回调在样本提交后执行，回调抛错不撤销已提交样本。
只有提交成功后才更新 payload 标识、缓存和成功统计。部分保存或失败批次不会把集合整体标记为已完整保存。
删除槽位不由保存参数隐式触发；显式重建和整理操作继续保持各自的删除语义。

SQLite v2 表和 H5 布局保持不变。每个样本写入新的 payload 版本，在一个 SQLite 事务内更新样本行、槽位索引和摘要。
H5 写入关闭后再提交 SQLite；旧 payload 在提交成功前保持不变，成功后成为无引用数据，由整理入口回收。
保留槽位采用 H5 存储级引用，不反序列化未选择的数组。schema 检查和旧版迁移只在数据事务前执行；未知的新 schema 版本明确拒绝。

单文件先写同目录临时文件再替换。集合 H5 使用暂存 group 与旧 group 备份；目录与属性表暂存全部更新后统一替换，失败恢复已替换文件。
属性表的共享 metadata 更新串行提交。

写入期间存在内部 `.dyntool-write-*.json` 标记。正常完成或成功回滚后移除；遗留标记阻止普通读写。
`inspect_storage_repository(..., level="quick")` 检查标记和结构；`deep` 进一步核对索引、单位、payload 与可重算摘要。
检查保持只读，并报告异常位置和原因。强制结束进程或断电后的自动恢复不在保证范围内；不要直接删除标记后继续覆盖数据。

## 迁移与验证

## 后续修复迁移（2026-10-05）

稳定性：`Public API`。传递函数采用输出/输入相位，历史结果相位可能与修正后相反；浮点采样率不再取整。相关历史派生结果需要显式覆盖重算，不自动改写旧仓库。错轴组合谱与缺失、空值、多值评价标量将明确拒绝，不能通过补零恢复损坏结果。

xarray 往返保持非 SI 物理量与可选依据；之前被错误单位恢复的对象不能自动识别和纠正。编辑数值或时间轴后须移除根和相关分量旧追溯。样本分支 commit(replace=True) 现在实际写回原槽位并返回样本，预览必须使用 replace=False。deep 增强可恢复性及重复依据检查，但不执行修复或迁移。严格标准编号继续不提供旧编号兼容，其他受支持载荷形态保留。
