# 核心库所有权、追溯与输出整改

稳定性：已有对象、计算 namespace 与导出方法属于 `Public API`；runtime port 属于 `Internal API`；本文中的状态聚合、写入计划和报告提交对象属于 `Private / implementation detail`。

本轮只修改核心库、验证、维护脚本及文档。GUI 继续运行原有回归，Web 路线不恢复；不发布版本，不重算用户仓库。公开参数、返回对象类型、SQLite v2 表及 H5 数组路径保持不变。

## 读取和修改的边界

`find()`、`find_many()`、`get_samples()` 返回独立的样本状态，查询不会重新绑定父集成员。副本共享不可变 NumPy 载荷，元数据、加载状态、派生状态和脏状态独立。`count()`、`exists()`、去重和元数据投影直接选择成员，不创建临时拥有者。

查询视图默认禁止写回源仓库，包括路径别名、源目录子路径、重建及整理。通用样本及子集使用 `compute` namespace 计算；已有直接批处理方法的样本类型边界保留。可以在内存重新计算，也可以导出或另存到独立目标。显式 `SampleSetViewOptions(access_mode=StorageAccessMode.READ_WRITE)` 仅写入所选成员；父集内存保持原状态，重新加载取得持久化更新。源摘要读取使用新的只读事务；懒加载批次只刷新所选 UID 的索引与槽位，避免逐样本全表刷新。

数组字段返回只读视图；构造时隔离调用者的可变数组。`xr`、`xr_base`、`to_xarray()` 返回独立可编辑快照。嵌套 metadata 字典、`data_vars` 和集合 `data` 返回映射快照；通过它们替换键值不改变内部状态。编辑数组时先 `.copy()`，再构造模型并调用 `update_data()` 或 `update()`。模型的 `convert_units(replace=True)` 更新拥有者脏状态和摘要，等价单位换算不使结果过期。

正式元数据更新先完整验证候选状态，再检查 UID 冲突；内部回调异常恢复 metadata、alias、集合键和脏状态。集合赋值、删除、更新、弹出和清空走同一成员绑定规则。继承的 `copy()` 也创建独立、默认只读的查询状态。一个样本状态只属于一个集合，加入另一集合时建立独立状态。

模型原位单位更新先形成候选表示，再通过私有发布对象替换并通知；通知失败或可捕获中断时恢复原模型、组合分量绑定、槽位追溯及样本和集合脏状态，可以重试。单独转换组合分量时，也同步父模型追溯中的输出单位。等价单位转换不改变物理版本，也不使现有结果过期。

## 结果追溯

模型和样本载荷通过可选 `_dyntool` / `_dyntool_state` 扩展记录操作、参数、输入槽位版本、输入输出单位、算法及库版本和 UTC 计算时间。H5 使用属性；SQLite 使用原有 JSON 与摘要字段；不新增表、不改变数组路径，也不写入用户身份 metadata 或参与 UID 计算。

结果状态为 `fresh`（依据已记录）、`stale`（已知输入改变）或 `unknown`（历史或外部来源没有计算依据）。未知来源不代表数值错误，也不会被伪造为有效计算。输入数值或时间轴更新使依赖结果过期；过期结果仍保留。重新计算需要 `overwrite=True`，否则报告明确跳过及过期原因。部分保存提交所选载荷及相关状态；未选中的数组仍由存储层保留。显式存储精度选项确实改变输入数值时，持久化输入采用可重复的精度版本，相关磁盘结果标记过期；内存中未舍入的结果状态保持独立。

旧数据继续可读，不自动重算或覆盖。旧版程序重新保存可能丢失可选追溯属性。CSV 是数值交换格式，单独的模型 CSV 不携带完整计算依据；样本属性表的追溯由既有 metadata JSON 保存。报告清单记录结果状态和表格单位。

存储精度仅改变数值载荷，不舍入追溯中真实执行的参数。交换一致性比较包含追溯，物理精度版本判断排除追溯表示；只有实际数值或单位数据改变时，才生成精度版本并处理派生失效。六种正式策略使用同一规则。

## 计算上下文

积分、微分支持“时间 × 通道”二维输入，沿第 0 维计算并保留形状。频谱、响应谱和评价继续要求单通道，调用者须先选择通道。

| 模板 | 消费字段 | 单位合同 |
|---|---|---|
| `accel_preprocess_template` | `input_unit_system`、`output_unit_system` | 数组输入按加速度单位解释；dt、截断时间为秒，滤波频率为 Hz |
| `freq_eval_template` | 数组的 `input_unit_system`、显式 `output_unit_system` | 无显式上下文时幅值保持输入单位；显式上下文同步改变数值和标签 |
| `resp_eval_template` | `input_unit_system`、`output_unit_system`、`damping_ratio` | 数值求解为 SI，模型以自身单位为准；阻尼比实际进入求解器 |

`extras` 只保存附加上下文，不自动展开为任意求解器参数。采样频率保持 `1/dt` 浮点值，不按整数 Hz 取整；窗口点数仍按离散采样规则确定。`base_units()` 表示模型内部存储单位，部分模型由构造时的单位系统确定，不能假设它总是固定 SI。

## 导出及迁移

`dyntool.reporting` 的标量、序列、峰值及图表使用相干 SI，dB 与无量纲保留语义。表头按成员及列记录单位，缺失首个成员不影响轴单位；Excel 增加“单位说明”页，清单包含单位和结果状态。普通 `scalar_frame()` 显示单位不变。峰检测参数按输入模型当前单位解释，检测完成后转换输出峰值。

单文件在同目录暂存，格式处理完成后替换。完整报告先生成全部产物再发布；已有非空目录必须包含有效清单，清单内路径须属于目标目录。保留清单外用户文件，新产物与它们冲突时拒绝覆盖。捕获异常恢复旧报告；无法确认回滚时留下具体位置的中断标记。单写者边界继续有效，不承诺断电或强制结束后的自动恢复。

通用交换载荷使用 `DefaultSample`、`DefaultSampleSet`。结构化数据与单位为权威来源，重复原始字段不一致时报错；高于支持范围的版本拒绝读取和重新输出。历史类别继续拒绝。

一致性检查也覆盖模型及组合分量重复的 `_dyntool` 追溯；两份同时存在但状态、依据或版本不同则拒绝恢复。旧载荷缺少一份可选追溯仍可读，不能通过静默选取一份来隐藏矛盾。

坐标和值区重复声明同名字段时也须一致，不允许字典合并覆盖。版本号要求规范的非负 ASCII 三段表示，拒绝负数、正号、空格、前导零和非 ASCII 数字。`fresh` / `stale` 追溯必须具有完整计算依据和带 UTC 时区的有效时间；历史条目须包含操作、参数和输入版本。缺少追溯的历史结果仍为 `unknown`，残缺的已知状态明确报错。

受限离线迁移入口：

```powershell
uv run python -B scripts/migrate_default_exchange_payload.py --input old.json --output migrated.json
```

该脚本只处理明确指定的单个样本或样本集交换文件，输出必须为新文件；仅修正已知错误类别，验证完整嵌套载荷后原子写出，保留源文件。不扫描或迁移工程仓库。文件命名在提交前校验名称、路径归属和不同 UID 的命名冲突；相同 UID 更新继续支持。冲突按可恢复样本错误处理，严格模式保留前序成功。`SAMPLE_JSON`、`SAMPLE_H5`、目录和属性表使用名称预约；集合 H5 与 SQLite/H5 的成员按 UID 定位，保留既有不消费样本文件命名器的行为，因此同一命名器返回值不会覆盖不同 UID。

## 私有结构和维护边界

模型状态聚合统一构造隔离、只读访问、表示变更通知和现有计算入口追溯；样本选择、身份更新、结果依赖、写入计划、报告提交分别聚合。未增加 NumPy/xarray 通用变更追踪框架、平行运行时或兼容门面。

四层依赖继续保持 `application -> domain/compute`、`domain -> compute`、`infrastructure -> domain`。依赖检查扩大到公开模块、类型叶模块与常量动态导入。层外 `storage` 负责领域与持久化组装；`reporting` 负责领域表、绘图和文件提交；`plotting` 只依赖领域绘图合同和配置；`logging`、`config` 各自独立。求解器允许依赖只读 `resources` 资产模块；该模块不依赖实现层。`storage.types` 与 `plotting.types` 限定为领域类型叶模块，禁止向实现层绕行。

验证见 [整改复核记录](core_architecture_verification.md)，既有数值和事务迁移见 [核心库修正说明](core_correctness_migration.md)。

## 后续正确性修复（2026-10-05）

稳定性：计算、模型交换和分支提交属于 `Public API`；内部依赖与检查聚合属于 `Private / implementation detail`。

- 传递函数统一为输出/输入响应，修正互谱相位方向。`fs` 使用浮点 Hz；模型采样率采用 `rtol=1e-10、atol=0` 比较，显式频率不重采样且不绕过两侧一致性校验。二维信号明确拒绝，不能展平通道。
- 幅值/相位以及各响应谱分量换算到 Hz/秒后校验形状和轴值，容差同上；允许等价单位，不插值、不按数组位置误对齐。
- 派生状态登记直接输入和全部可确认的当前槽位依据，历史输入与自更新分开；过期传播不依赖槽位顺序、不读取懒数组。旧依据不猜测修补，需显式覆盖重算。
- 样本计算流分支继承来源和提交回调；`replace=False` 返回结果，`replace=True` 原位更新原槽位并返回样本。主流保持独立快照，分支隔离可变上下文，写回失败恢复样本状态。无绑定的普通流返回结果。
- ZVL 的 zvl/aw、FPVDV 的 fpvdv、FDMVL 的 fdmvl 恢复须恰好有一个必需数值；缺失、空值、多值拒绝，不补零，不自动重算。OTOVL 可选派生字段的原规则保持。
- xarray Dataset/DataArray 交换保留维度及字段单位；字段 attrs、_units、_current_units 和显式 units 必须同尺度，可使用别名，不静默覆盖。根模型及分量追溯为可选 attrs；缺失来源保持 unknown。外部修改数值/轴后须移除根和相关分量旧追溯，独立快照不会改变原模型。
- 六策略 deep 按正式类别或已注册索引类型恢复槽位，定位字段、形状、单位、轴和追溯错误；未知扩展明确报告检查受限，不猜测类型。SQLite metadata、摘要和 payload 核对同版本完整依据，只允许合法的 fresh→stale 状态覆盖；quick 不读数组，检查均不修改源仓库。

样本属性表 CSV 本身不保存完整追溯，其 metadata JSON 仍是状态来源；deep 能核对载荷可恢复性、单位和已知输入依据，不能证明没有校验摘要的外部 CSV 数值未被修改。

自动 xarray 扩展路径保持可用，矩阵和标量保留原形状；响应谱的 T/period 关系由模型声明，不能应用于同样使用 period 字段的其他扩展。Dataset 字段单位校验包含已声明轴别名。
