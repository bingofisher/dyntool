# 内置资源与标准表

稳定性：`Public API`

当流程依赖标准输入时，应通过 `dyntool.resources` 获取，而不是在脚本里复制常量。

## 正式入口

- `dyntool.resources.keys()`
- `dyntool.resources.manifest()`
- `dyntool.resources.path(key)`
- `dyntool.resources.csv(key, ...)`
- `dyntool.resources.center_freqs(freq_range)`

## JGJ/T 170—2009 分频最大振级标准值

`limit_building_fdmvl` 对应《城市轨道交通引起建筑物振动与二次辐射噪声限值及其测量方法标准》表 4.0.1。场景名称直接取资源表的“区域类别”列，昼夜分别选择，不从样本时间戳猜测。

| 区域 | 昼间限值 / dB | 夜间限值 / dB |
|---|---:|---:|
| 特殊住宅区 | 65 | 62 |
| 居民文教区 | 65 | 62 |
| 混合区商业中心区 | 70 | 67 |
| 工业集中区 | 75 | 72 |
| 交通干线道路两侧 | 75 | 72 |

昼间为 06:00–22:00，夜间为 22:00–06:00；当地另有规定时按当地规定划分。标准适用于城市轨道交通列车运行引起的沿线建筑物振动，频率范围为 4–200 Hz，测量铅垂向加速度并按表 5.1.3 的 Z 计权因子处理。标准值对应分频最大振级，不能用于未计权倍频程结果或直接替代最大 Z 振级限值。

`z_weight` 对应表 5.1.3；`limit_building_fdmvl` 和既有资源键 `limit_building_zvl` 引用同一个 CSV，不复制数值表。既有键保留以避免破坏资源引用，其名称不代表该表是 Z 振级标准，新增代码应使用 `limit_building_fdmvl`。

来源核对：JGJ/T 170—2009 第 4.0.1、5.1.3、5.2、5.3 节；[民航局公开文件第 2.1.1 节的引用表](https://www.caac.gov.cn/XXGK/XXGK/GFXWJ/202301/P020230130321049517480.pdf)。本次接入该版标准值，不声称已核定新版或替代标准的有效状态。

限值对象不自动核验测点布置、有效列车次数、背景干扰、仪器或测点与列车工况汇总，读取阈值不能替代完整工程评价。
