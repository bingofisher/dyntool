# GUI 用户操作手册

稳定性：GUI 属于 `Internal API`。

主导航为“总览 / 导入与筛选 / 数据处理 / 图形绘制”。导出和子集管理沿用页面内入口，不增加主页面。

- 总览：查看当前项目和样本集，通过菜单保存项目或分析数据。
- 导入与筛选：选择来源，先检查再导入；筛选参数进入对话框，结果在工作区查看。
- 数据处理：选择动作，点击“处理参数”打开对话框；确认范围和覆盖策略后执行。取消参数对话框恢复原配置，结果预览显式触发。
- 图形绘制：配置来源及图形参数，点击“渲染”生成图形，再保存图片。

分析数据与项目分别保存；重新计算已有结果须启用覆盖。关闭或替换数据前处理未保存提示。完整合成项目的操作步骤见[建筑振动展示](usage/gui_building_showcase.md)。

旧布局手册及截图保存在原 GUI worktree 的快照中，未作为当前对话框式界面发布。
